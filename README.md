# Skill-Based Job Role Predictor

This project uses Machine Learning and NLP techniques to predict suitable job roles based on user skills. It is built using Python and Scikit-learn with a Naive Bayes classification model.

## Features
- Predicts job roles from skill inputs
- Uses CountVectorizer for text processing
- Multinomial Naive Bayes for classification
- Simple and beginner-friendly implementation
- JSON-based training dataset

## Technologies Used
- Python
- Scikit-learn
- NLP
- Machine Learning
- Naive Bayes Algorithm
